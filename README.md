## 📖 About The Project

This is my personal portfolio website that showcases my skills, projects, and contact information as a beginner web developer. The design focuses on **simplicity**, **readability**, and **responsive layout** — making it perfect for beginners who want to create their own online presence.

Whether you're a recruiter looking for a junior developer or another learner seeking inspiration, this portfolio represents my journey into web development.

---

## ✨ Features

- ✅ **Fully Responsive** — Looks great on desktop, tablet, and mobile devices
- ✅ **Smooth Scrolling** — Navigation links scroll gently to each section
- ✅ **Clean & Modern UI** — Card-based design with subtle hover effects
- ✅ **Section Animations** — Fade-in effects as you scroll down
- ✅ **Interactive Cursor Glow** — Gentle light effect that follows mouse movement (desktop only)
- ✅ **Active Navigation Highlight** — Current section is highlighted in the nav bar
- ✅ **Beginner-Friendly Code** — Well-commented, easy to understand and modify

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.) — optional, for editing

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ariyamerin682/Portifolio
   ```

2. **Navigate to the project folder**
   ```bash
   cd Portifolio
   ```

3. **Open the `index.html` file**
   - Double-click the `index.html` file, OR
   - Use Live Server in VS Code for a better experience

4. **Start customizing!**  
   Edit the content, colors, or add new sections as you like.

## 📱 Responsive Design

The portfolio automatically adjusts for different screen sizes:
- **Desktop (1200px+):** Full layout with side margins
- **Tablet (700px-1200px):** Reduced padding, flexible cards
- **Mobile (below 700px):** Stacked layout, smaller fonts

Test it by resizing your browser window or using Chrome DevTools mobile view.
